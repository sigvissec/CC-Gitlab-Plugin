# What does a Review produce, and where does it go?

Type: grilling
Status: closed
Blocked by: none

## Question

When Claude Reviews a Work Item, what does it check (clarity, acceptance criteria, Hierarchy consistency, stale Threads, missing fields), what shape is the output, and does it stay in the chat, get offered as a Comment, or get applied as suggested Edits? Is the checklist fixed or configurable per team?

## Closed: out of scope

The plugin is a thin bridge that Fetches Work Item data and carries out writes. Reviewing is Claude reasoning over Fetched data when the user asks, so there is no Review output, checklist, or destination for the plugin to define.
