# Matt Pocock's skills (vendored)

The skill folders in this directory come from https://github.com/mattpocock/skills
(MIT, see `LICENSE-mattpocock-skills`). They are the 27 skills that the upstream
`mattpocock-skills` plugin ships (v1.3.1, commit 49dd158). They're committed here so
every Claude Code session on this repo, including cloud sessions, loads them from the clone.

To update, re-copy each folder listed in upstream `.claude-plugin/plugin.json`.

Note: `code-review` has the same name as a built-in Claude Code skill.
